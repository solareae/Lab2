# Lab2
Dataset Name :
UNSW-NB15 Network Intrusion Detection Dataset
Machine Learning Problem Type
Classification (Supervised Learning)
Problem Statement :
The goal of this project is to build a machine learning model that can classify network traffic as either normal or malicious (attack) based on network flow features such as protocol type, service, packet information, and connection statistics. The dataset provides labeled network traffic records, and the model will learn patterns from these features to detect intrusions and suspicious activity. This problem is a supervised classification task because each record includes a target label indicating whether the traffic is normal or an attack.
Target Variable
label
0 = Normal traffic
1 = Attack traffic
Input Features
Examples:
protocol
service
state
duration
bytes sent/received
packet counts
other flow-based network attributes
